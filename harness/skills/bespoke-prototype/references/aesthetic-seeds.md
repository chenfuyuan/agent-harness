# 视觉基因种子库（Aesthetic Seeds）

> 内化自 `VoltAgent/awesome-design-md`、`Leonxlnx/taste-skill` 与 `anthropics/frontend-design`。
> **用法（只作质感参考，严禁直接套用！）**：这些只是用于激发配色气质、留白尺度与排版手感的审美灵感样本，**绝不是页面布局模板**！动手画原型前必须先从本项目的真实需求、核心对象与高频动作链原生推导页面分区，再按需借鉴局部质感调配出项目独有的 `DESIGN.md`；严禁照搬下述比例/栏位或为了“像某标杆”强塞冗余模块。

---

## Seed 1: Cinema & Storyboard Stage（影院与分镜画册创作室）
- **适用气质**：视频/音频剪辑审片、视觉叙事与多媒体创作工作流（对标 Frame.io / Apple Final Cut / 专业故事板工具）
- **三旋钮**：`Density: 5` · `Variance: 6` · `Motion: 4`
- **常见空间参考（非模板）**：中央大幅成片连播舞台 + 底部/画册式大尺寸分镜胶卷带（画面占主视野 ≥65%）+ 右侧自然排版的文本/参数抽屉，支持一键切换画册全景墙
- **色板灵魂**：拒绝冰冷高密度蓝黑监控感！采用温润暗房暖炭灰（`#171614` → `#201E1B` → `#2A2723`）或画纸浅色（`#F6F4EF` → `#FFFFFF`），搭配胶片朱砂/暖琥珀点缀，文案采用舒适阅读字体而非满屏代码字。
- **排版与几何**：圆角温润（`10px–14px` 画框感），画格带真实留白与悬停动态预览，仅时间码用等宽字体。

## Seed 2: Crisp Monochrome Workbench（极简刀锋工作台）
- **适用气质**：个人工作台外壳、研发协作、任务与知识编排（对标 Linear / Raycast / Vercel Geist）
- **三旋钮**：`Density: 7` · `Variance: 3` · `Motion: 3`
- **常见空间参考（非模板）**：顶栏面包屑+`Cmd+K`命令入口 + 主从分舱（左核心视图 `64%` + 右粘性详情检视抽屉 `36%`）或极窄图标轨
- **色板灵魂**：靠极细腻的中性灰度阶差建立秩序（浅色：`#FAFAFA` 画布 + `#FFFFFF` 主面 + `#F3F4F6` 胶囊；深色：`#0D0E11` + `#141519` + `#1D1F25`），黑白主按钮（深色白底黑字、浅色黑底白字），语义色仅作极小圆点（`6px` dot）或淡底标签点缀。
- **排版与几何**：圆角 `6px–8px`，无弥散大阴影，紧凑行高与行内微图表（Sparkline / Delta Bar）。

## Seed 3: Warm Editorial Studio（暖调纸感创作室）
- **适用气质**：长文写作与编辑、深度研报阅读、文档策划（对标 Anthropic Claude / iA Writer / Readwise Reader）
- **三旋钮**：`Density: 4` · `Variance: 6` · `Motion: 4`
- **常见空间参考（非模板）**：中央沉浸阅读/书写画卷（限宽 `680px–760px`）+ 按需滑出的双侧边批注/大纲轨 + 底部静默状态栏
- **色板灵魂**：告别刺眼纯白与冷黑——暖羊皮纸画布 `#F7F5F0`、卡片 `#EFECE6`、墨黑正文 `#1C1B18`、暖灰辅字 `#6E6A61`、赤陶红/赭石强调色 `#C96442`（深色为暖炭色 `#191816`）。
- **排版与几何**：标题与正文可配人文衬线（`Newsreader` / `Songti SC` / `Source Serif`）搭无衬线 UI 控件，充裕行距 `1.7`，让人静心阅读。

## Seed 4: Infinite Canvas & Floating Dock（无界画布与悬浮工具坞）
- **适用气质**：关系知识图谱、流程图、节点编排与创意白板（对标 Figma / Excalidraw）
- **三旋钮**：`Density: 6` · `Variance: 7` · `Motion: 5`
- **常见空间参考（非模板）**：`100vw × 100vh` 点阵或暗格无限画布铺底 + 顶部悬浮药丸项目条 + 底部中央悬浮工具 Dock + 右侧按选中节点浮现的半透明毛玻璃属性面板（`backdrop-filter: blur(16px)`）
- **色板灵魂**：点阵画布背景（`radial-gradient` 极淡网格点），悬浮面板采用高不透明度玻璃态 + 精致 `1px` 内高光边框。

## Seed 5: Tactile Industrial Utility（实体工业硬件风）
- **适用气质**：独立效率小工具、音频/媒体处理器、自动化脚本控制台（对标 Teenage Engineering / Braun 博朗设计）
- **三旋钮**：`Density: 6` · `Variance: 8` · `Motion: 4`
- **常见空间参考（非模板）**：紧凑设备面板式构图（居中或模块化硬件机架感，带清晰的物理拨杆开关、段码指示灯与网格刻度）
- **色板灵魂**：阳极氧化铝灰 `#E5E5E0` + 哑光黑模块 `#1A1A1A` + 高饱和国际橙 `#FF5500` 状态触发键，机械感等宽标签。

## Seed 6: Focused Consumer Craft（高质感消费级单流）
- **适用气质**：对外 SaaS、商业插件、C 端移动端独立产品（对标 Stripe / Wise / Apple 极简流）
- **三旋钮**：`Density: 4` · `Variance: 5` · `Motion: 6`
- **常见空间参考（非模板）**：分步聚焦流、Bento 不对称重点网格或居中 `390px × 844px` 真实移动设备视口框
- **色板灵魂**：清透高明度底色、明确单一品牌主色、大字号核心结果反馈、友好的零门槛空状态插画/引导按钮。

## Seed 7: Obsidian Precision Cockpit（黑曜石高频数据座舱 · 仅限数字监控域）
- **适用边界**：**仅限**实时监控、高频数值面板、底层服务器遥测（内容创作、媒体、办公与消费类产品**严禁套用**！）
- **三旋钮**：`Density: 9` · `Variance: 2` · `Motion: 2`
- **常见空间参考（非模板）**：`100vh` 全视口停靠舱（`1px` 细格线分割面板），高频数值强制 `tabular-nums` 等宽对齐，圆角克制（`2px–4px`）。
